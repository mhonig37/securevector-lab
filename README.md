# SecureVector Lab

A hands-on PostgreSQL and pgvector lab for exploring vector search,
database performance, security, and AI-oriented data infrastructure.

## Environment

- PostgreSQL 17
- pgvector
- Linux
- Git

## Goals

- Learn PostgreSQL vector data types and operations
- Compare exact vector search with approximate indexing
- Explore HNSW and IVFFlat indexes
- Analyze vector query performance
- Build a document embedding and semantic-search pipeline
- Develop a small RAG architecture
